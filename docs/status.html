각색의 선 (사용자 결정)

형식은 자극적으로

  • 궁금증을 부르는 질문·반전 제목과 첫 문장
  • 짧은 구어체, "그런데", "여기서 반전" 같은 전개
  • 숏츠: 위쪽 고정 큰 제목(강조어 빨강), 가운데 당사자 사진·짧은 영상, 큰 자막

내용은 보도된 사실만

  • 서로 다른 언론사 원문 2개 이상을 Claude가 직접 읽고 대조
  • 의혹·루머는 "~라는 보도/주장", 수사·재판 중은 "혐의"
  • 사생활 추측, 미성년자·피해자·일반인 신상, 모욕·혐오 제외
  • 기사 문장 베끼기·기사 사진·방송 화면 사용 안 함. 인물 사진은 재사용 허락된 Commons 자료만, 혐의자·피해자·미성년자·일반인 제외. 정정 요청 시 즉시 내림

하루 자동 흐름 (KST)

  1. 02:10뉴스 수집Google 뉴스 종합·연예 RSS에서 후보 25건

  4. 02:30~검사·검수규칙 검사 → 독립 검수(원문 대조, 명예훼손 위험) → 반려 시 재작성
  5. 02:45~영상·배포Commons 사진 검색·Claude 사진 검수 → 숏츠 2편 → YouTube → 블로그
